# 星际突击 3D

这是一个使用 Three.js 制作的 3D 射击游戏，适合直接在浏览器中运行。

## 运行方式

1. 进入项目目录。
2. 用任意静态文件服务器启动：

```bash
python -m http.server 8000
```

3. 浏览器打开：

```text
http://localhost:8000
```

## 操作说明

- W / S / A / D：移动飞船
- 鼠标移动：瞄准
- 左键 / 空格：射击
- 目标：击杀敌机，避免敌机进入战场并造成损伤

## 游戏特色

- 3D 空间飞行视角
- 连续敌机波次
- 分数、护盾和关卡系统
- 粒子爆炸与星空背景
- 自适应画面尺寸

## 代码结构

- `index.html`：页面入口
- `style.css`：界面与布局样式
- `game.js`：核心游戏逻辑与 Three.js 场景

## 说明

这个项目不依赖额外的 npm 安装，直接用浏览器打开即可。适合学习 WebGL / Three.js / 3D 游戏开发。
